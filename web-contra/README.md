# Jungle Vanguard

`web-contra` 是一个可直接打开的原创复古横版跑射 Web Demo。它以 8-bit 丛林突击关卡为灵感，实现了第一关的横向推进、平台跳跃、敌兵/炮台、Boss 碉堡、HUD、射击反馈和浏览器合成器音乐。

> 说明：本项目没有拷贝《魂斗罗》的受版权保护角色、美术、地图或原曲素材；所有角色、关卡视觉和音乐均为原创/程序生成，以降低版权风险。

## 运行

```bash
cd web-contra
python3 -m http.server 8000
```

然后在浏览器访问 <http://localhost:8000>。

## 操作

- 移动：`A` / `D` 或 `←` / `→`
- 跳跃：`W` / `↑` / `Space`
- 射击：`J` / `K` / `Enter`
- 重开：结束后按 `R`
